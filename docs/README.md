# 条目文件

这里放**引用条目**：一份文档一个文件，里面写它是什么、转换丢过什么、
以及从它里面引出来的原话。

`cite-check.mjs` 默认扫描本目录。条目里的引用长这样：

```markdown
## 某论文.pdf

- 转换: pymupdf 1.27.2 @ 2026-09-17
- 保真度: 双栏顺序有错乱；表格未保留
- 可引用: 原文（正文）／仅页码（表格、公式）
```

**上面这段是围栏里的示例，工具会跳过它** —— 否则文档自己的格式示例
会被拿去 `library/` 里找，必然失败。

引用本体要写在围栏外，而且**不要包进反引号**：

```markdown
“We propose a new simple network architecture”（library/某论文.md:32）
```

包进反引号 = 放弃核验。

## 为什么条目要和资料分开

条目是**你写的判断**（这份资料可信到什么程度），资料是**转换出来的文本**。
两者寿命不同：换提取器重跑，资料会变，判断不一定变。
混在一起的话，重跑一次转换就会把判断冲掉。

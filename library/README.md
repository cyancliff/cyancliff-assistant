# library/ — 可引用的资料

**原件和转换产物放一起，同名同前缀：**

```
library/某论文.pdf      原件（不进版本管理）
library/某论文.md       转换产物（进版本管理）
```

同名同前缀是硬要求：从任何一条引用 `library/某论文.md:42`，
不查表就能推出原件路径。

## 为什么原件必须留着

> **md 是检索与引用的载体，原件是真相的载体。**

转换产物永远是**派生品**，引用因而是**暂定**的 —— 除非能在原件里复现。
删掉原件，那段引文就再也无法核对了。

## 为什么 md 要进版本管理而原件不进

引用（写在 `docs/` 里）是指向 `library/*.md:<行号>` 的。如果 md 不进版本管理，
换个克隆之后每一条引用都解析不了 —— 引用等于悬空。

md 很小（一篇论文几十 KB）、是纯文本、可以 diff。原件动辄几 MB 且多为二进制，
进版本管理只会把仓库撑爆。

## 转换

```bash
python scripts/pdf-to-md.py  library/某论文.pdf
python scripts/docx-to-md.py library/某论文.docx --redact library/某论文.redact.json
```

转换后**务必抽查四类最容易崩的地方**，再决定可引用性：

| 类别 | 通常结果 |
|---|---|
| 跨页段落 | 尚可 |
| 双栏版面 | **顺序可能串** |
| 表格 | **结构基本会丢** |
| 公式 | **上下标会降级** |

抽查通过才写「可引用: 原文」；表格和公式那一类要单独降级说明。
**降级要有证据，不要猜。**

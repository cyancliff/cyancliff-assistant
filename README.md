# CyanCliff Assistant

把文档变成**可引用、可核验**的 Markdown。

零依赖：Node 脚本只用内置模块，Python 脚本只需要 PyMuPDF。

---

## 解决的问题

让 AI 摘要一份材料很容易。但**一份漂亮的摘要，不能证明阅读真的发生过** ——
更麻烦的是引用：模型给出的"出处"，你没法确认那句话到底在不在原文里。

这三个工具围绕一个观察：

> 既然引用的是**原文**，那么"引用能不能在原件里被重新找到"
> 就是一个**可以程序化验证**的性质。

于是"出处可查"从一句承诺变成一条命令。

---

## 三个工具

### `cite-check.mjs` — 引用核验器

扫描条目文件里的引用，检查每一条能不能在资料里重新找到。

```bash
node scripts/cite-check.mjs                 # 扫描 docs/
node scripts/cite-check.mjs docs/某条目.md   # 只检查一个文件
node scripts/cite-check.mjs --explain       # 打印引用格式
node scripts/cite-check.mjs --scan notes --root .
```

引用格式：

```markdown
library/某论文.md:42                文本原生资料
“引用原文”（library/某论文.md:42）   带到行号，引文可以跨行
（library/某论文.pdf 第7页）          只到原件，没有 md
```

它会区分三种失败，因为**修法完全不同**：

| 报出 | 含义 |
|---|---|
| 引文和第 N 行**不完全一致** | 行号对了，但字符有差异（上下标、全角半角） |
| 引文**不在第 N 行**，实际在第 M 行 | 行号漂移了，引文本身没问题 |
| 引文**整份资料里都找不到** | 这条引用是坏的，不要当它成立 |

细节：

- **比对时空格宽松、字符严格。** 不换行空格、全角空格、普通空格视为同一个
  （`0.5` 后面跟不换行空格还是普通空格，是同一句话，肉眼也看不出差别）；
  但 `σ02` 和 `σ²₀` 算不同字符。
- **代码围栏和反引号行内代码会被跳过。** 否则文档自己的格式示例会被拿去核对。
  代价是：**引用包进代码里 = 放弃核验**。
- 围栏之外的示例可以用 `<!-- cite-check:off -->` … `<!-- cite-check:on -->` 圈起来。

### `pdf-to-md.py` — PDF 转 Markdown

面向"有文字层"的 PDF（不是扫描件）。

```bash
python scripts/pdf-to-md.py library/某论文.pdf
```

处理了两件容易出错的事，都是实测撞出来的：

- **span 之间的空格重建.** PyMuPDF 会把一行切成大量小 span（引用编号、
  逗号各自成 span）。直接拼接文字，`English` + `to` + `-German` 会粘成
  `Englishto-German`。按 x 坐标判断该不该补空格。
- **行尾连字符一律保留.** PDF 里行尾连字符混合了**真实断词**
  （`transduc-`/`tion`）和**本来就有连字符的复合词**（`English-`/`to-German`）。
  没有字典就分不清，而猜错会把复合词粘错 —— 那是主动污染正文。
  保留只是留下一个可见的断词痕迹（`transduc-tion`），不损坏任何文本。

### `docx-to-md.py` — Word 转 Markdown

```bash
python scripts/docx-to-md.py "某论文.docx"
python scripts/docx-to-md.py "某论文.docx" --redact library/某论文.redact.json
```

docx 是 zip + XML，**Python 标准库就能读**，不需要装 python-docx。

按段落样式映射标题层级（章 / 节 / 小节），并**支持脱敏**：
论文封面常带学号这类不该被随手引用的信息，`--redact` 在**写文件之前**替换掉，
产出里根本不存在原值。规则文件里写的是正则，所以它自己也不留原值。

> 样式名到标题层级的映射是按常见 Word 论文模板写的。
> **换模板要重新核对，不要以为它通用。**

## 目录约定

```
docs/       条目文件：一份文档一个，写它的保真度和引用
library/    资料：原件 + 同名同前缀的转换产物（.md 进版本管理，原件不进）
scripts/    三个工具
```

**md 与原件同名同前缀**是硬要求 —— 这样从引用能直接推出原件路径，不用查表。

---

## 这套东西的边界

说清楚，免得把"绿了"当成超过它实际含义的东西：

- **`cite-check` 只保证到 md 这一层。** 它不判断 md 是否忠实于 PDF 原件 ——
  那需要解析器。所以「原文」类可引用性是**弱承诺**：引文在 md 里找得到，
  不等于 md 忠实于原件。
- **转换不保证忠实。** 表格结构基本会丢，公式上下标会降级，双栏顺序可能串，
  图片只剩图注。这些都在条目里如实记录，并且**按类别降级**
  （比如「可引用: 原文（正文）／仅页码（表格、公式）」），而不是笼统写"原文"。
- **原始资料永远不要删。** 派生品可以重做，原件不能。
